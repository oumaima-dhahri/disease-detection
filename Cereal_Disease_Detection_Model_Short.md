# Cereal Disease Detection Model: Research Contribution and Business Value

## Context

This research is part of the **"Cereals Resiliency Revolution for Agile Supply Chain Management in the Mediterranean"** project, developed for **SQLI-services**. The work implements an advanced **computer vision-based disease detection system** for cereal crops (wheat, barley, field peas, lupins) using deep learning, contributing to the project's goal of building resilient agricultural supply chains.

## State of the Art & Research Contribution

The system leverages a state-of-the-art convolutional neural network architecture, to achieve real-time disease classification from leaf images, directly supporting the supply chain resilience objectives of the project.

### Technical Innovation


**Implementation Highlights:**
- Real-time image processing pipeline with standardized preprocessing
- Multi-input support: file upload, drag-and-drop, and webcam capture
- Integrated recommendation system providing treatment guidance for each detected disease
- Seamless integration with the platform's AI assistant for contextual advice

### Research Contribution

As a researcher, this work demonstrates:
1. **Practical AI Application**: Successful deployment of deep learning in agricultural domain
2. **System Integration**: Seamless integration of ML models into production web applications
3. **User-Centric Design**: Development of intuitive interfaces for non-technical users
4. **Scalable Architecture**: Design supporting multiple deployment modes and future extensibility
